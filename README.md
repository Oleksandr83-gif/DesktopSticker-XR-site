# DesktopSticker XR public site

This repository contains **only** the public, static project-description site for DesktopSticker XR. The Android application source, APKs, signing material and internal engineering documents are deliberately absent. The app is a working pre-release prototype; no purchase or download is offered yet.

GitHub Pages serves `index.html` and `style.css` from the root of `main`. The site has no JavaScript, analytics, cookies, external font requests or build step. Its feature and release-status text must be checked against the private app repository before publication updates. Privacy/terms pages for a paid release require finalized seller information and legal review; this site is not currently presented as those final documents.
