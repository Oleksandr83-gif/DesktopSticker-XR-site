# DesktopSticker XR public site

This repository contains the static project website for DesktopSticker XR, an app that brings paper-like notes to Quest Home. The application source is maintained separately.

GitHub Pages serves `index.html` and `style.css` from the root of `main`. The site has no JavaScript, analytics, cookies, external font requests or build step. The release date and distribution model have not been announced.

The header uses separate pages, not section anchors: `index.html`, `experience.html`, `details.html`, `status.html` and their Russian counterparts under `ru/`. `pages.css` contains the shared page layout.
